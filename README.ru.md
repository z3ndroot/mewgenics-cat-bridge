# Mewgenics Cat Bridge

**Claude видит ваших котов в запущенной [Mewgenics](https://store.steampowered.com/app/686060/Mewgenics/) и помогает ими управлять.**

Небольшая DLL-модификация читает память игры в реальном времени, а Python-сервер [MCP](https://modelcontextprotocol.io) превращает эти данные в инструменты для ИИ-ассистента. Он видит характеристики котов, их способности, мутации и родословную, комнаты дома, а также советует, кого скрещивать, брать ли бродягу и кого отправить в поход. Умеет и редактировать котов: характеристики, пассивки, части тела.

[English version](README.md)

> Неофициальный фанатский проект. Не связан с Эдмундом Макмилленом, Тайлером Глейелом и издателями Mewgenics и не одобрен ими.

## Что можно спросить

- «Каких двух котов скрестить на силу и телосложение без инбридинга?»
- «Составь план разведения на три поколения к семёркам во всех характеристиках»
- «Стоит ли брать сегодняшнего бродягу?»
- «Какие коты не нужны для разведения? Собери из них команду в поход и подбери ошейники»
- «Как обставить комнату Floor1_Small для разведения?»
- «Покажи родословную Сосакуса. Душенька — продукт инцеста?»
- «Дай Бухославу пассивку Стиль Жабы» / «Вылечи Гримурыра от оспы»

## Возможности

| Раздел | Инструменты | Что делают |
|---|---|---|
| Коты | `list_cats`, `get_cat` | Характеристики как в игре, с разбивкой на базу (наследуется) и бонусы (класс, предметы, пассивки, мутации, травмы); способности и пассивки с названиями как в игре (русский и английский); мутации; комната; бродяга у дома |
| Семья | `get_family` | Родители, предки, братья и сёстры, дети и коэффициент инбридинга для любого кота, который когда-либо был в сохранении |
| Разведение | `evaluate_pair`, `suggest_breeding_pairs`, `plan_breeding` | Родство и COI котёнка, совместимость по полу и ориентации, какие характеристики, мутации и способности может унаследовать котёнок и с каким шансом, план на несколько поколений |
| Бродяги и роли | `evaluate_strays`, `breeding_roles` | Брать ли бродягу; кто нужен роду, а кем можно рискнуть |
| Походы | `suggest_adventure_team` | Команда из котов, не нужных для разведения, и класс (ошейник) для каждого |
| Дом | `get_rooms`, `suggest_room_setup` | Параметры комнат как в игре (Comfort с учётом тесноты, Stimulation, Evolution, Health, Appeal), мебель по комнатам, что куда переставить и что искать в магазинах |
| Редактирование | `set_cat_stat`, `set_cat_passive`, `find_passives`, `set_cat_body_part`, `set_cat_hp` | Изменить базовые характеристики, пассивки и болезни, части тела (мутации); каждое изменение возвращает старое значение для отката |

## Что нужно

- Windows и Mewgenics в Steam — **версия игры 1.1.21239** (см. [Обновления игры](#обновления-игры))
- [Python 3.10+](https://www.python.org/downloads/windows/), **64-битный**, с галочкой «Add python.exe to PATH» при установке
- MCP-клиент: [Claude Desktop](https://claude.ai/download) или [Claude Code](https://docs.claude.com/en/docs/claude-code)

## Установка

1. Скачайте `mewgenics-cat-bridge-vX.Y.Z.zip` со страницы [Releases](https://github.com/z3ndroot/mewgenics-cat-bridge/releases/latest) и распакуйте куда угодно, например в `C:\mewgenics-cat-bridge`.
2. Установите Python-пакеты: откройте терминал в этой папке и выполните
   ```
   pip install -r requirements.txt
   ```
3. Подключите к Claude.

   **Claude Desktop**: Настройки → Developer → Edit Config, добавьте (путь свой, с двойными обратными слешами):
   ```json
   {
     "mcpServers": {
       "mewgenics": {
         "command": "python",
         "args": ["C:\\mewgenics-cat-bridge\\mcp_server\\server.py"]
       }
     }
   }
   ```
   Перезапустите Claude Desktop.

   **Claude Code**:
   ```
   claude mcp add mewgenics -- python C:\mewgenics-cat-bridge\mcp_server\server.py
   ```

## Каждый раз при игре

1. Запустите Mewgenics и загрузите сохранение (нужно быть в доме).
2. Дважды щёлкните **`inject.bat`**. Должно появиться `injected ... into pid ...`.
3. Общайтесь с Claude.

Мод работает, пока открыта игра. После каждого запуска игры `inject.bat` нужно запускать заново. `eject.bat` выгружает мод, не закрывая игру.

Папка игры находится автоматически через Steam. Если не нашлась, задайте переменную окружения `MEWGENICS_DIR` с путём к папке, где лежит `Mewgenics.exe`.

## Безопасность

- **Чтение ничего не меняет.** Редактирование (инструменты `set_*`) меняет память запущенной игры, и игра сохраняет эти изменения как любые другие. Claude должен спрашивать перед изменениями, а откатить можно всегда: каждое изменение возвращает прежнее значение.
- **Сохраняйтесь перед экспериментами.** Игра к тому же сама делает резервные копии в `%APPDATA%\Glaiel Games\Mewgenics\<id>\saves\backups`.
- Мод сверяет точную версию игры (SHA-256 файла `Mewgenics.exe`) и на любой другой версии **не включается**, чтобы не гадать.

## Обновления игры

Этот релиз собран для Mewgenics **1.1.21239**. После обновления игры мод не включается (инструменты отвечают «timed out» или «could not connect»), пока не выйдет релиз с поддержкой новой версии. Если вы собираете из исходников, обычно обновить можно самому за минуту — см. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md#after-a-game-update).

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `could not connect to \\.\pipe\cat_bridge` | Мод не загружен: запустите игру, загрузите сохранение, запустите `inject.bat` |
| `Mewgenics.exe is not running` | Запустите игру до `inject.bat` |
| `needs 64-bit Python` | Установите 64-битный Python |
| `timed out waiting for game thread` | Игра на экране загрузки или «заморожена» в фоне — переключитесь на неё. То же бывает на неподдерживаемой версии игры |
| `game data unavailable` / нет бонусов класса | Не найден `resources.gpak` — задайте `MEWGENICS_DIR` |
| Видны не все коты | Нужно быть в доме: другие экраны пока не поддерживаются |

## Как это работает

```
Mewgenics.exe ── cat_bridge.dll (внедрена) ── именованный канал ── mcp_server (Python) ── Claude
                 читает и пишет память игры                       + данные игры из resources.gpak
```

DLL встраивается в покадровое обновление игры и выполняет одну команду за кадр в игровом потоке, поэтому никогда не трогает память, пока игра её меняет. Всё, что она знает, получено обратной разработкой и сверено с интерфейсом игры, её файлами данных и форматом сохранения. В [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) перечислено, что проверено, а что остаётся гипотезой. Коротко:

- **Проверено в игре:** формула итоговых характеристик, наследуемая база, мутации частей тела и то, как они складываются, Comfort комнаты со штрафом за тесноту, родословная и коэффициент инбридинга (совпадает с игрой на каждом коте), кто живёт в доме, а кто бродяга, редактирование характеристик, пассивок и частей тела.
- **Измерено на реальном сохранении:** наследование способностей (≈32% — врождённая способность родителя, ≈2% — выученная, ≈66% — случайная).
- **Гипотеза:** как стимуляция влияет на шанс унаследовать лучшую характеристику (пороги 32 / 95 / 196 взяты из [другого проекта](https://github.com/jph6366/mewgenics-mcp)). Инструменты предупреждают, когда используют её.

## Сборка из исходников

Нужна Visual Studio 2022+ (или Build Tools) с компонентом «Desktop development with C++».

```
git clone https://github.com/z3ndroot/mewgenics-cat-bridge
cd mewgenics-cat-bridge
pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File mod\build.ps1      # -> bin\cat_bridge.dll
```

С флагом `-Console` рядом с игрой откроется окно с логом. Архитектура, протокол канала и то, как исследовать новые структуры, описаны в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) (на английском).
